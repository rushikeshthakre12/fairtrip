# ⚠️ Demo/Prototype Dataset

`fairtrip_prices.csv` is **synthetic data**, generated by `generate_dataset.py`
with a fixed random seed (`42`) for reproducibility. It is **not** real-world
collected fare data.

It is provided so the prototype has something realistic to train on. It
should be **replaced or augmented with validated real-world observations**
(exported from the `validated_prices` table — see `ARCHITECTURE.md`, section 5)
before any production use.

Columns: `city, service_type, distance_km, hour, day_of_week, month, vehicle_type, price`

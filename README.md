# ✈️ FairTrip

### AI-Powered Fair Price Intelligence for Travelers

> **Know the Price. Travel with Confidence.**

FairTrip helps travelers understand whether a local transportation quote is **typical, low, or unusually high** using machine learning and OCR.

Instead of guessing what a taxi or auto *should* cost, FairTrip analyzes the trip details and provides an **explainable price estimate and comparison**.

---

## 🚀 What FairTrip Does

**Enter a quote → Analyze it → Understand the price**

```text
Trip Details
     ↓
FastAPI Backend
     ↓
Machine Learning Model
     ↓
Typical Price Range
     ↓
Quote Comparison
     ↓
FairTrip Result
```

### 🔎 Example

**Mumbai · Taxi · 15 km · 8:30 PM · ₹900**

FairTrip analyzes the trip and compares the quoted price against the model's estimated local range.

> The result is generated by the actual trained model — not hardcoded.

## 🧠 Machine Learning

FairTrip uses a **Random Forest Regressor** trained on trip characteristics such as:

* City
* Service type
* Vehicle type
* Distance
* Hour
* Day of week
* Month

The estimated range is calculated from the model's prediction and the **residual standard deviation measured on held-out test data**.

### Current Prototype Metrics

| Metric | Result |
| ------ | -----: |
| MAE    | ₹31.98 |
| RMSE   | ₹49.55 |
| R²     |  0.966 |

> These metrics come from the latest training run on the prototype dataset.

## 📷 OCR — Scan & Check

FairTrip can read transportation quotes from images using:

**Tesseract OCR + pytesseract**

Example:

```text
Taxi
Mumbai
₹900
```

↓

```text
Service → Taxi
Price   → ₹900
```

Users must verify extracted information before it is used for analysis.

## 📊 Dataset

The current prototype uses a **synthetic deterministic dataset containing 4,000 rows**.

It is intended for development and demonstration, not as a representation of actual market prices.

The long-term goal is to improve the model using **validated real-world fare observations**.

---

## ⚠️ Current Limitations

* Synthetic prototype dataset
* Taxi and Auto/Rickshaw only
* 7 supported cities
* OCR depends on image quality
* Community submissions require validation
* No user authentication yet
* Confidence score is not a formal statistical confidence interval

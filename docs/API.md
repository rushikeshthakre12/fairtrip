# FairTrip — API Reference

Base URL (local dev): `http://localhost:8000/api`

Interactive docs (Swagger UI) are auto-generated by FastAPI at `/docs`.

---

## `GET /api/health`

Returns service status for the DB and the ML model.

```json
{ "status": "ok", "database": "connected", "ml_model": "loaded" }
```

## `GET /api/cities`

Returns the list of currently supported cities.

## `GET /api/services`

Returns the list of currently supported services (`Taxi`, `Auto`).

## `GET /api/model-info`

Returns real evaluation metrics from the last training run (MAE, RMSE, R²,
residual std, dataset notice, per-city/service coverage counts). Powers the
Model Transparency page.

---

## `POST /api/predict`

The core endpoint. Runs the trained RandomForest pipeline and returns a
structured price analysis.

**Request body:**
```json
{
  "city": "Mumbai",
  "service_type": "Taxi",
  "distance_km": 15,
  "date": "2026-08-30",
  "time": "20:30:00",
  "quoted_price": 900,
  "vehicle_type": "Sedan",
  "pickup_location": "Airport",
  "destination": "Bandra"
}
```

`vehicle_type`, `pickup_location`, `destination` are optional.

**Response (200):**
```json
{
  "city": "Mumbai",
  "service_type": "Taxi",
  "distance_km": 15.0,
  "quoted_price": 900.0,
  "predicted_price": 394.17,
  "estimated_range": { "min": 344.63, "max": 443.71 },
  "status": "UNUSUALLY_HIGH",
  "confidence": "HIGH",
  "explanation": [
    { "factor": "distance_km", "value": "15.0 km", "note": "...", "importance": 0.575 }
  ],
  "disclaimer": "This is an estimate based on available data...",
  "dataset_notice": "ml/data/fairtrip_prices.csv (DEMO/PROTOTYPE — synthetic)",
  "low_data_notice": null
}
```

**Errors:**
- `422` — invalid input (bad city/service, non-positive distance/price)
- `503` — ML model unavailable (not yet trained / failed to load)
- `500` — internal error (never leaks a stack trace)

## `POST /api/community-reports`

Submit a real trip observation for review.

**Request body:**
```json
{
  "city": "Mumbai", "service_type": "Taxi", "distance_km": 15, "price": 480,
  "trip_date": "2026-08-15", "trip_time": "20:00:00",
  "vehicle_type": "Sedan", "notes": "Prepaid taxi counter"
}
```

**Response (201):** the created report with `status: "PENDING"`.

Reports with an implausible price-per-km ratio are rejected at submission
time (`422`) as a basic sanity check.

## `GET /api/community-reports?status=PENDING`

List reports, optionally filtered by `PENDING` / `VALIDATED` / `REJECTED`.

## `POST /api/community-reports/{id}/validate?decision=VALIDATED`

Prototype admin action. `decision` is `VALIDATED` or `REJECTED`. Only
`VALIDATED` reports are copied into `validated_prices` — the table used to
export future training data.

---

## `POST /api/ocr`

Multipart file upload (`file`). Runs Tesseract OCR and attempts to extract a
service keyword and a price from the raw text.

```json
{
  "raw_text": "TAXI FARE CARD\nTotal: Rs 650",
  "extracted_service": "Taxi",
  "extracted_price": 650.0,
  "verification_notice": "Please verify the extracted information before analysis."
}
```

The frontend never sends OCR output straight to `/predict` — the traveler
must confirm/edit the values first.
